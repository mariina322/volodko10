# Публикация через GitHub Pages

1. Создайте публичный репозиторий GitHub.
2. Загрузите содержимое этой папки в корень ветки `main`.
3. Откройте `Settings -> Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Укажите ветку `main` и папку `/ (root)`.
6. Нажмите `Save`.
7. После публикации GitHub покажет адрес вида `https://username.github.io/repository/`.
8. Откройте опубликованную страницу и проверьте числовой ввод, ползунки, палитры, UCR/GCR и предупреждения.
